How this was run

  • Graded on the final state. The checker opens the saved session or runs the submitted program, renders the audio itself and measures it. Hidden answer keys never enter the agent's sandbox.
  • Same harness for every model: same tools, same budgets. An error or timeout counts as not completed.
  • Music is made, not retrieved. Code writes the notes; they are played by our virtual instruments (sampler instruments built from the Rightsify catalog) or by code the agent writes.
  • Every task passed a self-check first: the reference answer passes, doing nothing fails, and scripted wrong answers fail.
  • Cheats caught in the run. In an early REAPER run, a model reached outside its project and read an answer file. REAPER now runs sandboxed and those attempts were rerun.
  • Models: Claude Opus 5.5 (Anthropic), GPT-6.1 Sol (OpenAI), Gemini 4 Argon (Google), Kimi K3.1 Pro (Moonshot AI).
